# Doginn – Plataforma de gestión de guarderías caninas

Doginn es un proyecto web desarrollado como Trabajo de Fin de Grado (CFGS ASIR), orientado a la gestión y reserva de guarderías caninas.  
El proyecto simula un entorno real de producción, cubriendo tanto la parte backend como frontend, así como la gestión de base de datos.

Demo (entorno de pruebas), es un dominio de pruebas del hosting, completamente funcional:  
https://41259534.servicio-online.net/

## Estructura del proyecto

- `/includes` → conexión a base de datos y lógica común
- `/css` → estilos y diseño responsive
- `/js` → scripts y funcionalidades
- `/imagenes_guarderia` → imágenes de guarderías
- Archivos PHP para:
  - Registro y login
  - Reservas
  - Gestión de guarderías
  - Paneles de usuario

---

## Seguridad y buenas prácticas

- Datos sensibles **no incluidos** en el repositorio
- Credenciales gestionadas mediante archivos de configuración
- Base de datos no subida a GitHub (solo estructura y lógica)
